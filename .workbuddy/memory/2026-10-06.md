- 将本地 8356 端口服务接入 heq-portal 引导页：在 `services.config.js` 的 `window.HEQ_SERVICES` 新增一项（slug=`local-8356`、`name`/描述/图标为占位），`targetUrl` 设为公网反代地址 `https://638rember.me/local-8356/`。线上需在 nginx 443 server 块加 `location /local-8356/ { proxy_pass http://127.0.0.1:8356/; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; }` 并 `nginx -s reload`。
- 关键约束：引导页跳转是浏览器端重定向，`targetUrl` 填 `localhost` 仅本人同机访问才通；外网/手机访问必须走 nginx 反代填公网地址。另需把改后的 `services.config.js` 同步到线上 root 同目录才会生效。
- 整理：删除 blog/gallery/opensource 三个示例项，仅保留 8356 服务并命名为 openGym；slug=`opengym`，`targetUrl` 路径由 `/local-8356/` 改为 `/opengym/`。线上 nginx 的 `location` 需相应改为 `/opengym/`（proxy_pass 仍为 `http://127.0.0.1:8356/`），否则跳转 404。
